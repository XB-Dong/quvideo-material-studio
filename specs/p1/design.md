# P1 视觉设计规格

版本P1-1.1.0。方向：蓝紫暮光创作台。背景深而有层次，图片提供主要色彩，蓝紫用于操作与选中；少量漫射光形成氛围，正文与错误信息有稳定实色承载。参考选择与本地素材见 docs/waves/P1/references/README.md；可视提案见该目录direction-board.svg。

## 设计 token

| Token | 值 | 用途 |
| --- | --- | --- |
| background | #0B1020 | 页面底色 |
| surface | #141A30 | 制作/历史/弹窗面板 |
| surfaceRaised | #1D2540 | 控件、浮层与悬停 |
| text | #F4F5FF | 正文和标题 |
| textMuted | #B8C0DD | 描述和辅助文字 |
| accentPurple | #7050D9 | 按钮左端/选中实色 |
| accentBlue | #3157BF | 按钮右端 |
| accentLight | #B6A2FF | 链接、focus与强调文字 |
| border | #3B476B | 装饰边界；关键控件再用高对比轮廓 |
| success / danger / warning | #76E0B3 / #FF9FB3 / #F3D291 | 状态搭配文字/图标，不能仅靠颜色 |

主按钮白字覆盖accentPurple→accentBlue渐变；整条渐变的最差对比需实测，不能只检测端点。普通文字目标≥4.5:1、大字号≥3:1，依据[W3C说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。准备阶段只核算实色配对，最终图片叠字/透明度/focus仍需在页面测量。状态卡必须保留状态文字。

间距采用4/8/12/16/24/32/48/64px；控件圆角12、卡片18、面板24px。正文15px/1.65，辅助12–13px，卡片标题18px；主标题桌面48px、小屏32px。使用本机Arial、PingFang SC、Microsoft YaHei等fallback，中文排版优先，避免外部字体阻塞加载。主按钮高48px，图标/小屏交互目标至少44×44px（项目选择）。

## 布局与构图

桌面内容最大1440px，左右32–48px；列表4列并保留图片呼吸空间，不复制无关工具导航。列表封面3:4，制作详情封面按内容使用16:10，结果完整预览contain。主体焦点/人像脸部/宠物耳部不被裁切；候选照片横图在3:4卡片裁切以人工核对为准。卡片文字置于独立底部或稳定暗渐变底，不直接叠在高频纹理上。

制作页保持约360–400px左面板+剩余历史，gap24；历史卡桌面2–3列。小于900px堆叠，375px页面16px边距，模板可1–2列，历史优先1列保证原因可读；分类横向滚动但不拦截页面竖向滚动。

首页轻量hero左文右图（Orbit/Glow），随后实用模板网格，再接紧凑四页签灵感画廊（Dither/Ripple/Halftone/Pixel）；同屏动效协调详见react-bits.md。画廊不是新的业务路由，主CTA Electric Border短触发。列表引导不扩大成阻挡创作的营销长页；按钮、图片、信息有共同基线。黑色不压掉图像细节；边框/透明玻璃仅用于层级，不让所有区域都发光。品牌继续“映作”，保留其文字标识并重绘为本项目简单几何标记。

## 组件状态

按钮：idle/hover/focus/pressed/disabled/submitting，禁用使用真实disabled；光晕不替代focus。上传：空位/选图预览/上传中/就绪/失败/替换/移除，提供文字状态。任务：排队/三个Java阶段/成功/执行失败/查询异常。空/加载/请求失败也纳入同一设计。

顶部导航提供一键“动态效果”开关；“动效设置”详细偏好放身份面板中的辅助区，提供跟随系统/静态两档，存本地偏好，不进用户数据库；系统要求reduce时始终静态。它管理视觉运动，不影响任务执行。基础功能在动效库加载失败时仍可操作。


## 页面文案

特效自然融入图片、留白和操作反馈，不在前端加说明性文字。页面不展示组件名、技术名、特效原理、参数或“此处使用……特效”等注释，也不添加“移动鼠标体验”“悬停查看效果”“点击体验动画”等引导。作品画廊以创意、旅行、人像、宠物等内容题材命名，不以特效名或演示名组织界面。

保留品牌、内容标题、导航、操作、上传要求、真实状态/错误、动态效果开关及必要的无障碍名称。暂停和静态控制用简短操作名称，不解释实现。组件映射、参数和验收操作只写在开发文档/取证记录；源码维护注释和第三方许可照常保留。
