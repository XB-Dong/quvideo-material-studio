# P1.1 需求与范围

版本P1.1-1.0.0，用户于2026-10-30提出并在准备封存后明确启动。P0.1为用户确认的笔误，阶段统一为P1.1。原R-01～R-14仍为业务底线，P1历史证据不追改。实际验证状态见波次报告，不以规格存在代表通过。

| ID | 要求 | 可观察结果 |
| --- | --- | --- |
| P11-BRAND-01 | 映作改为疏影 | 当前页头/页脚、标题/描述、图标/加载与空态等可见品牌一致；会话/库/卷/仓库不改 |
| P11-AUTO-01 | 删除动态与暂停按钮，默认常动 | 无动态/静态/暂停/继续控制；旧静态偏好不抑制正常动态；reduce/后台等自动保护仍有效 |
| P11-INK-01 | 浅水墨与擦镜清晰 | 正常可辨浅墨；鼠标无需按下即可留下同画面清晰笔迹并柔回雾，真实默认软件路径也能体验 |
| P11-EDGE-01 | 多种动态边框、更鲜明 | 电弧、流光、追光、像素分段至少三种可辨差异；蓝紫边线持续，当前交互卡更突出；不遮字/闪白/抖布局 |
| P11-CARD-01 | 效果融入探索灵感 | 删除灵感作品专区；Dither/Ripple/Halftone/Pixel按稳定模板ID进入真实卡片，整卡单链接、首次触屏直接进入详情 |
| P11-QUALITY-01 | 创意与舒适双保证 | 默认可见动态；系统reduce、真coarse、后台/离屏/卸载、单GPU、无交互归因>50ms长任务；美学五维各≥4/5；图片/JS逐轮预算 |
| P11-REG-01 | 业务与数据保持 | Java业务/API/SQL/模板数量要求/上传/提交/多任务/查询异常/刷新与身份隔离不退化，原业务测试继续通过 |
| P11-MAIL-01 | 本仓库CI邮件治理 | 旧失败与当前状态可区分，定向规则只匹配本仓库Actions邮件；其他仓库/人工PR与安全通知不误伤；不删必要CI/不改全账号开关 |
| P11-DEL-01 | 工程与真实交付 | 完整CI、来源/锁文件/报告/验收SHA/实际投入与限制、源码包/部署回滚；只准备阶段不标已实现 |

用户指令替代P1手动开关、Orbit hover暂停、Electric仅600ms、单独gallery和最多两运动系统的旧视觉契约。新的持续动态/资源边界见[design](design.md)与[effects](effects.md)；业务契约及历史真实结果保持。四模板视觉映射不是在前端写死业务数据，列表/详情/上传/任务继续来自Java。
