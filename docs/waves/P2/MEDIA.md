默认GIF，评估者无需视频播放器。源录制可为WebM/MP4保留在仓库外，除非GIF质量/大小确实无法满足再向用户说明替代，不擅自只交静态图。最终README/提交说明引用实际GIF相对文件或附件名，静态图可作fallback，但不冒称展示了动态。

Acceptance在性能测量全部结束、产品写入冻结后单独录制；视频/截图捕获成本不计入或替代无截图性能结果。录制与转码工具仅在工具容器中使用，P2-BASE核对可用版本/镜像并记录，不在应用增加依赖。

画面须能辨认光标位置及跟随关系，使用真实连续鼠标输入；若需录制指针辅助，限定在工具/成片并如实记录，不进入产品、不改变光圈/尾迹或阶段。禁止为拍摄假造动画、逆放、延长清晰区、隐藏错误或把多个状态拼成服务端真实连续过程。可以选择无敏感数据的干净演示，不拍cookie/token/开发者工具/邮箱/真实上传或个人文件对话框路径。

转码以清晰度优先，建议约8～12fps、适当缩放和palette优化；不要因过度压缩把浅色水墨变成一片灰。无额外特效名称、技术注释或营销标签。保留实际页面语言/画面比例，不拉伸、不改品牌。

实际验收：Final Reviewer播放整段至少一遍，核对首/中/末、鼠标与清晰区位置、山水/蓝紫细线可辨、没有闪烁/严重跳帧、文件可循环解码且总时长合理；Acceptance记录源SHA、录制环境/窗口/媒体/renderer、实际动作、模拟配置、工具命令、帧数/fps/时长/尺寸/字节/哈希。实际文件<100MB，目标每个<=20MB，附件总数<=6；目标20MB未达但官方门槛通过时如实说明，不伪称失败或悄悄丢掉山水演示。

GIF仅用于动态展示，不能代替核心测试、查询只读/跨用户隔离等断言。公开版录屏仍按源码/素材归属审计，第三方照片不得宣称本人原创。
