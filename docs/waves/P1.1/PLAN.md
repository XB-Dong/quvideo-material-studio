# P1.1 疏影：水墨与模板交互计划

版本P1.1-1.0.0。基准e485792839d6c3af1a6587a8964f983250366b39。准备已于325bfd8本地封存；用户于2026-10-30明确“启动P1.1”。当前进入执行，按冻结契约开发、容器验证、独立审核和交付。首次远端推送前完成仅本仓库通知治理。

## 目标与界面

品牌统一为“疏影”。延续浅色背景、白色阅读面板、蓝紫细节，用可见的动态边框、浅水墨和鼠标擦雾形成更鲜明的风格。首页为“创作引导 → 探索灵感真实模板网格 → 页脚”，删除独立“灵感作品”及其页签、空白占位；原四种图片互动进入可直接点开的模板卡片。界面不写特效名、技术注释或鼠标体验提示。

删除“动态效果/静态模式”和“暂停/继续”按钮，也不转移到隐藏设置。正常可视区默认持续动态：边框低频运行，Orbit缓慢运行，背景与卡片随指针响应；忽略旧yingzuo-static=true，避免老用户无入口恢复。系统reduce、离屏、后台、路由卸载和实际低性能仍自动保护，弹窗及上传/历史阅读区降低装饰注意力，不改变真实业务状态。

水墨以吴云《仙霞新霁图》公开领域影像为参考：清冷纸白/淡灰墨底，白色内容面板，蓝紫线条。正常状态可辨山水但隔着柔雾；鼠标移动沿轨迹擦出同一画面的清晰细节，保留约2–3秒，再约1秒自然回雾。不是一个光圈照亮纯色，也不要求点击或拖拽。

## 九项任务与推进

| 顺序 | 任务 | Owner | 结果 |
| --- | --- | --- | --- |
| R0 | P11-BASE | Leader | 复读文件地图、冻结实际SHA/来源/兼容边界、容器及P1可比基线 |
| R0 | P11-CI-MAIL | Leader | 只处理本仓库CI邮件；核对旧失败、预览/应用邮箱定向规则、验证不误伤；首次远端push前完成 |
| R1并行 | P11-ASSET | Asset | 水墨画心衍生、来源/哈希/图片预算；不改原模板封面/结果/数据库 |
| R1 | P11-BRAND | 唯一Frontend | 疏影品牌、去动态/暂停控制、旧偏好兼容；系统自动策略 |
| R2 | P11-SCENE | 同一Frontend | 浅色水墨擦雾和多种连续边框，默认软件路径也可见 |
| R2 | P11-CARDS | 同一Frontend | 四效果迁入真实卡片、去gallery、分类/点击/键盘/触屏完整 |
| R0–R3 | P11-ACCEPT | 独立Acceptance | 提前设计，卡片集成后验证视觉/业务；最终签署同时等待P11-CI-MAIL证据 |
| R3 | P11-REVIEW | 独立Reviewer | 资产席位释放后审实际界面，美学五维各≥4/5 |
| R4 | P11-DELIVERY | Leader | 双门槛、CI与邮件任务完成，报告/源码/回滚和真实投入，然后停止 |

一主最多三子；同一Frontend依次BRAND→SCENE→CARDS，避免多人改Shell/globals.css。Asset只写背景资源与转换目录，Acceptance不改产品，Reviewer只写审核文件。角色见[ROLES](ROLES.md)，输入/输出与路径在[tasks](tasks/P11-BASE.md)。

## 执行门槛与交付

需求/设计/动效/来源/CI邮件契约、文件地图、任务DAG、验收与独立准备审阅齐备，才标准备完成；它不等于启动授权。启动后先做短而真实的2D擦雾+边框验证，不因GPU软件退化把关键体验全部关闭；随后完成卡片迁移和品牌。若效果既不可见又占资源，要修实现，不靠放宽标准或删除检查通过。

没有业务API或数据库迁移计划。保留Java业务、MySQL数据/文件卷、匿名身份及历史；不因品牌改名重建数据库/会话。P1封存e485与匹配数据库/文件备份是回滚基线，前端退回须恢复可兼容版本，不能删除持久卷。

预估有效投入6–10小时，含验证/修正/交付，非截止承诺或已耗事实。记录实际AI会话墙钟和未知人工投入，平行角色时间不相加。每60–90分钟检查产物；同一根因两次无效修正后保留原rootTaskId并重新诊断有界方案。

本轮准备只本地封存，避免现有workflow因文档push再发通知。执行P11-CI-MAIL后再正常推送；不使用skip-ci、continue-on-error或关必要检查来处理邮件。通知作用域由用户确认仅本仓库，账号全局Actions邮件设置不在本轮授权范围。
