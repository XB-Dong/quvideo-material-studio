# P1.1 参考与提案

这里只存启动前参考和静态示意，不是已实现的“疏影”截图，也不证明新动效性能/舒适通过。

- 用户模板网格截图与GitHub通知截图见assets/user-template-reference.png、assets/user-ci-mail-reference.png；仅表达布局/问题。
- 水墨主参考：[吴云《仙霞新霁图》](https://www.metmuseum.org/art/collection/search/737785)，官方Public Domain/CC0证据、原下载哈希与尺寸见manifest.json。实际查看DP-42597-004，未来取画心去黑边/色卡/大字；准备未生成生产图。

- React Bits官方当前head/完整许可哈希、三项新选型的registry源码文件哈希/import审计见reactbits-audit.json。现有七项源码/许可继续以P1冻结记录与已vendored文件为准；没有执行安装CLI或复制新组件到产品。
- Electric Border作为电弧来源；Glare Hover用于方向光泽的边缘适配；Magic Bento只取边缘追光思路，不引入整套布局/图标依赖。默认2D/CSS/SVG基础实现与真正上游shader增强将分别登记，不混称已采用。
