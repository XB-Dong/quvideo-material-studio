# 小影科技素材制作网站需求文档

版本：1.0.0；日期：2026-10-29；作者：董信步；状态：P0 启动前规格基线。原题编号保持不变；下文“实现选择”是本项目方案，不改写原题要求。

## 目标与用户流程

交付独立运行的网站：浏览分类模板 → 查看详情 → 上传模板所需图片 → 提交任务并立即获得任务 ID → 继续浏览或创建其他任务 → 查看个人历史、后台阶段、成功图片或失败原因。刷新和关闭页面不终止后台执行，刷新后从 Java/MySQL 恢复记录。

生成无需真实 AI。后台顺序执行素材检查、模拟生成、结果整理，每一步有独立执行边界和数据库记录。重点是 Java 后端组织异步任务、前端维护独立异步状态，以及可运行、可解释的交付。

## 必需需求

| 编号 | 原题要求的整理 | 可观察验收 |
| --- | --- | --- |
| R-01 | Next.js App Router、React、TypeScript；Java、Spring Boot、MyBatis、MySQL。模板、素材、任务和个人记录业务由 Java 提供，状态与历史持久化 | 检查源码、锁文件、Java 路由与 SQL；容器闭环确实读取 MySQL |
| R-02 | 模板分类、卡片、标题、封面，分类筛选与详情导航；数据来自 Java，可用种子/数据库，不要求模板后台 | 至少两种分类，存在不同图片数量要求；接口响应改变列表内容；所有素材可离线访问 |
| R-03 | 详情标题、描述、封面、要求和对应上传位；选择、预览、替换、移除、上传中/失败；数量、类型、大小双端校验；未就绪和提交中防重复；不存在/加载/空/失败反馈；文件真实上传 | 空位不能提交，非法/超限图片被两端拒绝；替换失败可恢复；页面刷新后后端仍可访问上传文件 |
| R-04 | 必要校验及建记录后立即返回任务 ID，不等待制作；Java 后台继续执行，可排队或并行；关页不中断 | 配置慢任务，受理先返回；停止浏览器后任务仍完成 |
| R-05 | 素材检查 → 模拟生成 → 结果整理；各步独立可观察；持久化当前阶段、状态、结果或失败原因；结果可预览；查询只读；终态稳定 | 多次读取能看到数据库中的阶段；不查询也执行完成；终态重复查询不回退 |
| R-06 | 可重复指定某阶段失败，失败停止后续步骤，保存阶段及原因；耗时可调整；README 写清方法 | 对三个阶段逐一注入失败，后续步骤没有启动记录；使用慢配置观察队列与运行 |
| R-07 | 区分上传、提交、排队/运行、成功、失败；受理后展示任务并解除提交态；展示阶段/原因/结果；查询异常不等于执行失败 | 任务运行时模拟 GET 失败，保留旧状态并显示查询异常，可恢复；真实执行失败显示服务端原因 |
| R-08 | 连续多任务，相互独立；自动跟踪未完成任务，终态停止、无未完成时停轮询；离页/换用户清理，旧响应不串数据 | A 失败、B 成功、C 排队各自正确；终态及离页后无多余请求；迟到响应不能写入新用户缓存 |
| R-09 | 个人历史展示创建时间、状态、结果/原因；刷新从 Java 恢复，继续跟踪未结束任务；成功图可预览 | 硬刷新/重开页恢复；活跃任务继续变化；历史成功结果仍可访问 |
| R-10 | 自行设计用户身份和个人记录；README 说明方案与演示 | 两个浏览器会话的上传、任务和结果隔离，不能靠修改 taskId/assetId 取得他人记录 |
| R-11 | 参考对应截图主要布局，桌面完整、小屏可操作；语义、键盘焦点、上传和图标标签；截图题外功能不扩展 | 列表分类与卡片、详情左制作右历史；窄屏堆叠；Tab 操作、错误提示和预览对话框可用 |
| R-12 | push/PR 自动运行前端 lint、TS 检查、构建及 Java 测试/构建；关键测试验证后端顺序/失败中断，前端多任务/查询异常区别 | 提交真实 CI 配置，检查命令不跳过，保留对应 SHA 的执行结果；包含核心行为测试 |
| R-13 | 完整前后端、准确版本/锁文件、数据库结构/初始化、CI、README；源码仓库注明验收 commit，压缩包不含缓存 | 按下列交付清单核对；可读源码/压缩包实际可取得，交卷后不再修改 |

## 推荐项与实现选择

R-14 推荐一条 `docker compose up --build` 启动前端、Java、MySQL 与初始化数据；本项目将它作为 P0 交付门槛。提供 Dockerfile、非敏感配置示例、健康检查和命名卷。评估者构建、安装、测试和运行均在容器隔离环境，不要求在宿主机运行项目脚本。

模板计划至少四个，覆盖创意/人像/宠物分类、1/2/3 张图片要求。产品默认只接受 JPEG/PNG、单文件 5 MiB；具体值以 Java 模板响应为准，而不是浏览器写死。结果为预置原创图片，无真实图像处理。此处数量和限制是项目选择，不是原题强制值。

## README 最终交付清单

1. 技术准确版本、目录、构建/测试/启动命令，前后端与数据库连接。
2. 配置项与无真实凭据示例，数据库初始化、模拟数据和素材准备。
3. 主要接口、请求/响应、状态、阶段与后台执行方式。
4. 成功、指定阶段失败、耗时、多任务、刷新恢复的可复现步骤。
5. 身份及个人记录方案，两个用户的演示方式。
6. 完成/未完成/未验证、已知限制、实际投入与取舍，包括重启边界。
7. 基本部署、备份与回滚步骤。
8. 是否使用 AI；如使用，说明拆分、上下文、生成修改、验证修正，至少一个实际实例，不提交私人聊天/账号。
9. 脚手架、开源代码与素材来源及复用范围。

## 非目标与提交说明

不做真实 AI/支付、复杂模板后台、积分会员、第三方账号、国际化、多区域、集群/消息队列运维、服务重启自动续跑。幂等受理、断点续跑、自动重试可讨论取舍，不是缺失扣分项。

最终交付可为可读取仓库、本地目录或源码压缩包。通过收到题目的沟通渠道提交源码；具体提交日期按双方约定。题面当时显示的剩余时间只是会话快照，不是本项目确认截止。交卷控件一次最多 6 文件、单个 100MB、不限格式，不能误用作网站素材约束。当前不代为交卷，也不联系招聘方。
