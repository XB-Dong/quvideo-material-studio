# 决定 0003 多 Agent 协作

日期：2026-10-29。采用主 Agent 加最多三个原生子 Agent；准备阶段只生成角色与任务包，不派发开发。P0 启动后默认前端、后端、测试并行；专项只读审核在释放席位后运行。

继承当前会话模型与推理设置，不擅自切换；请求和可核实的实际路由分开记录，无法核实用 null。

并行写入使用独立外部 managed worktree、codex/ 分支；精确基准提交、契约版本和允许路径是派发前置条件。主 Agent 管共享契约/依赖/CI/Compose/迁移序号，单文件同一时刻只有一个写入者。实现者写行为测试，测试角色做独立验收，只读审核不改产品。

发现包含复现步骤、位置、严重度、证据；主 Agent 决定采纳/拒绝/暂缓，修复后核验。相同根因两次修复失败后记录诊断与替代路径，不通过换名重置次数。主 Agent 负责合入、集成验证和最终报告。
