# 决定 0004 参考项目方法的适用范围

阅读的来源与提交见 THIRD-PARTY-NOTICES.md。采用 ccagent 当前的 docs/waves/<wave>/PLAN.md 目录方式，避免根目录堆积多个计划；采用 classroom-annotator 的英文任务包、外部工作树、独立验收、事实记忆与交接方式。

保留 SDD 追踪和有意义的 TDD；只记录实际发生的测试和审核。角色并非常驻进程，不为了形式增加编排系统。任务状态有依赖、根任务、修复累计和证据。

不继承云主机、公司材料、付费额度、历史期限、模型分配、持续自动跨波和定时授权。旧项目 AGENTS 中的指令是参考内容，不能覆盖本项目用户的“P0 启动前停止”。
