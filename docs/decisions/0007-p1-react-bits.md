# 决定 0007 P1 七组件创意编排与双门槛

P1采用Dither Veil、Glow Cursor、Ripple Distortion、Halftone Reveal、Orbit Images、Pixel Trail、Electric Border，并要求创意丰富且美学/舒适都通过。规格P1-1.2.0；当前为P1启动前准备。

采用hero的Orbit/Glow、单一CTA Electric、四互斥页签的Dither/Ripple/Halftone/Pixel编排；瓷白/浅灰背景静态，蓝紫用于细线/边框/图标/少量动作强调，上传/任务/真实结果稳定。所有七项正常桌面可演示，同视口最多两个活跃系统和一个已分配存活WebGL；旧拥有者释放后才挂载下一个，仅停RAF不够。提供一键静态、系统reduce优先、触屏/小屏/离屏/后台/低性能退化。

Frontend同一写入者按VISUAL→CREATIVE→MOTION推进；九任务包，投入估算10–14小时，非截止承诺。Reviewer独立美学五维各≥4/5，Acceptance独立舒适全部通过，Leader处理发现并复验，无开放blocking/major才完成；不能全关效果取代创意实现。

七组件TS-CSS registry/14文件哈希及MIT + Commons Clause许可已只读核对；Motion14.7.1和OGL1.0.11分别为MIT和Unlicense候选，未安装。运行兼容、真实包体、帧率与双门槛待P1。初始JS新增35KiB、延后创意JS新增体积总120KiB、首视口图片800KiB为起始预算，实际测量若需调整必须显式归因/修订并重审。

独立准备审阅提出的MIME、Flyway回滚、OGL许可与WebGL分配所有权已纳入契约和任务。P0产品/依赖/数据库/现行服务不变。
