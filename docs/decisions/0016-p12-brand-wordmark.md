# 左上角品牌字标

用户在P1.2执行期间明确要求修改左上角“方框疏字+疏影+英文副标题”，认为其过于模板化。该请求作为本轮直接执行范围，首页保留规则对品牌角标作这一项明确例外，不扩展到其它已认可内容。

采用简洁中文“疏影”字标，以本地可靠中文字体、深墨色和留白建立辨识度；移除方框单字、重复字与英文副标题。蓝紫限于极轻的线条/交互细节，不新增渐变图标、字体下载或运行依赖。品牌仍为原生首页链接，保留清楚可访问名称、键盘焦点；桌面/小屏头部92/76px及响应布局稳定，避免重引入CLS。

唯一Frontend在日期性能修正后顺序提交品牌代码，Reviewer据桌面/375实际图独立检查美学，Acceptance补首页/链接/头部几何并对最终代码做必要性能预算复验。其它首页布局、素材、水墨和四卡不变。当前状态为执行中，未因文本方案即宣布完成或审美通过。
