# Read-only Reviewer Role

Read only assigned specifications, diffs and evidence. Preparation review is limited to documents and must not start P0, install dependencies, edit product files or spawn implementation agents. During P0, check asynchronous boundaries, persistence, ownership, version races and missing acceptance. Output blocking/major/minor findings with locations, contradictions and concrete corrections. Record unverified runtime claims explicitly. Leader decides disposition; a review response alone is not evidence of application execution.
