# 源码包范围与读取

源码ZIP是当前完整应用的评估者视图：前后端、全部测试、依赖锁、CI、Compose/Dockerfiles、数据库迁移/种子、本地素材、API与业务规格、必要许可、来源清单、实际演示和最终验收说明全部保留。

包不携带.git、依赖/构建/运行缓存、数据库或上传卷、认证cookie、原始个人参考/邮件截图、完整原始题面附件、内部任务/交接/审阅协调档案及给作者的私有报告。内部记录仍由作者在私有Git中保留，没有通过打包清理重写历史。给作者的逐条符合性报告作为单独文件交付，不默认附给招聘方。

筛选由跟踪的.gitattributes export-ignore与package-policy.json明确列出，只排除非执行私人文档；不是删减功能或遗漏源码。独立检查会比对全部frontend/backend/tests和必要入口均存在，并从解压包运行Compose。照片/水墨重做工具的合法原图输入仍按原相对路径保留，当前来源元数据统一在docs/assets/provenance.json，不含本机缓存绝对路径。

ZIP根目录直接是README.md/compose.yaml等，不额外加前缀。候选与最终包分别绑定commit、文件entries/hash；后续报告/GIF加入时明确非执行差异，任何实际运行内容或命令变更需要重新验证。最终外部manifest记录SHA256、CI与文件大小，避免自含哈希循环。

私库链接不保证评估者可读，默认源码ZIP解决读取。未来直接将现有仓库改public仍会暴露全部可达历史/分支等，源码ZIP清理不能代替全历史审查；本轮不会改public或重写历史。可采用审过的干净应用快照作为未来公开基础，具体历史处置另需用户明确操作授权。
